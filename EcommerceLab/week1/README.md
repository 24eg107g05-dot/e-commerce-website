# Week 1 — Home Page and Login Page (E-commerce Shoe Store)

## Aim
To design an e-commerce home page (`index.html`) displaying featured shoe products and a customer login page (`login.html`) with form inputs using semantic HTML elements.

## Files Created
- `index.html`: Store front page containing header, navigation bar, product listings with prices and categories, and contact footer.
- `login.html`: Customer authentication page with username/email, password fields, submit, and reset controls.

## Prerequisites
- Any modern web browser (Google Chrome, Firefox, Microsoft Edge).

## How to Run / Test
1. Open the folder `EcommerceLab/week1/` in File Explorer.
2. Double-click `index.html` to open it in your browser.
3. Click the **Login** link in the navigation menu to navigate to `login.html`.
4. Fill in the login credentials and test the form controls (submit button and reset button).

## Expected Output
- **Home Page**: A clean HTML layout showing the store title *SoleStride Shoes*, navigation bar, four shoe products with descriptions and prices ($65 to $190), and store details.
- **Login Page**: A form enclosed in a fieldset with username/password inputs, remember me checkbox, and submit/clear buttons.

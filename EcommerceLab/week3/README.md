# Week 3 — Applying CSS to Home and Login Pages (E-commerce Shoe Store)

## Aim
To enhance the visual aesthetics, layout, and responsiveness of the e-commerce home page (`index.html`) and login page (`login.html`) using an external Cascading Style Sheet (`style.css`).

## Files Created
- `style.css`: Contains CSS rules for:
  - Flexbox header and navigation bar styling.
  - CSS Grid for responsive 4-column product cards.
  - Card elevation, hover animations (`transform: translateY(-4px)`), and product badges.
  - Styled login card with input focus states and styled action buttons.
- `index.html`: Linked to `style.css` displaying shoe cards with prices, categories, and "Add to Cart" buttons.
- `login.html`: Linked to `style.css` displaying a centered, elevated customer login card.

## Prerequisites
- Modern web browser.

## How to Run / Test
1. Open `EcommerceLab/week3/index.html` in your browser.
2. Observe the gradient header, navigation links, and styled product cards.
3. Hover over each product card to observe subtle lift and shadow effects.
4. Click **Login** in the header to view `login.html`.
5. Observe the centered card with smooth input focus styling and modern buttons.

## Expected Output
- Responsive shoe store landing page with clean blue gradient header, grid layout cards with prices ($65 - $190), and a polished login form card.

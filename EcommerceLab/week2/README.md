# Week 2 — Registration Page (E-commerce Shoe Store)

## Aim
To construct a comprehensive customer registration form (`register.html`) using HTML form input controls, validation attributes, and structured layout.

## Files Created
- `register.html`: Contains registration input fields including customer full name, email, 10-digit phone number, password, preferred shoe size dropdown, multi-line address textarea, terms agreement checkbox, submit button, and reset button.

## Prerequisites
- Any modern web browser.

## How to Run / Test
1. Navigate to `EcommerceLab/week2/`.
2. Open `register.html` in Google Chrome or another browser.
3. Attempt to submit the form without filling required fields to observe standard HTML5 validation popups.
4. Fill in dummy data and click **Reset Form** to test clearing input fields.
5. Enter valid details and click **Register Now** to test form submission.

## Expected Output
- A neatly aligned HTML form containing table-arranged labels and inputs, dropdown for shoe size, address textarea, submit and reset action buttons.
